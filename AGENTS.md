# Horizon Lida Green — Shipping Portal

## Commands
- `npm run dev` — start dev server at http://localhost:3000
- `npm run build` — production build
- `npm run start` — run production build
- `npx prisma studio` — browse/edit the SQLite database visually
- `npx prisma db seed` — re-seed the admin user
- `npx prisma migrate dev --name <name>` — apply schema changes

## Stack
- Next.js 14 (App Router) + TailwindCSS + SQLite (Prisma)
- Auth: JWT in httpOnly cookie (bcryptjs password hashing)
- DB file: prisma/dev.db

## Notes
- Admin creates clients (auto-generates password if none given; password shown once on creation).
- Clients log in with their email + the password set/generated by admin.
- Admin creates shipments and updates status; each status change is logged as a tracking event.
- Clients see only their own shipments with a progress timeline and tracking history.
