# Horizon Lida Green — Shipping Portal

## Commands
- `npm run dev` — start dev server at http://localhost:3000
- `npm run build` — production build
- `npm run start` — run production build
- `npx prisma studio` — browse/edit the SQLite database visually
- `npx prisma db seed` — re-seed the admin user
- `npx prisma migrate dev --name <name>` — apply schema changes

## Setup
- Copy `.env.example` to `.env` and fill in your Supabase URL + service role key + JWT_SECRET
- Tables must exist in Supabase (created via Prisma migration or SQL script)
- `npm run seed` — create/update the admin user
- Admin creates clients (auto-generates password if none given; password shown once on creation).
- Clients log in with their email + the password set/generated by admin.
- Admin creates shipments and updates status; each status change is logged as a tracking event.
- Clients see only their own shipments with a progress timeline and tracking history.

## Documents & Insurance Claims
- No DDL access to Supabase (REST-only, no DATABASE_URL): files + metadata live in the private Storage bucket `shipment-documents` (auto-created by `src/lib/storage.js`).
- Per shipment folder `shipment-<id>/`: uploaded files under `files/` and `claim/`; document + claim metadata in versioned manifests under `_data/` (a new manifest object per write — `list()` is always fresh, `download()` of a previously-requested path can serve a stale cached copy, so never overwrite a manifest in place).
- Shared constants (doc types, claim statuses, 14-item claim checklist): `src/lib/docs.js`.
- API: `api/shipments/[id]/documents` (list/upload), `.../documents/[docId]` (signed-URL download, delete), `.../claim` (CRUD + checklist status/notes/file removal), `.../claim/upload` (client or admin file upload → item becomes SUBMITTED).
- Client portal polls `/api/shipments` every 15s for live updates; claim/doc changes also write a `ShipmentEvent` so they appear in tracking history.
- Admin manages files & claims via the "Docs" button on each shipment (`src/app/admin/ShipmentDocs.js`).
